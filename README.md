# Palm Deck

スマホを Stream Deck の代わりにするアプリです。PC で `palm-deck` を起動し、スマホでQRコードを読み取るとボタンが並んだ画面が開きます。

- スマホ側はブラウザだけで動きます（iPhone / Android。アプリのインストールは不要です）
- PC 側は実行ファイルが1つだけで動きます（Windows / Mac / Linux。Python などの追加インストールは不要です）
- 曲の再生・停止・送り、音量、アプリやURLを開く、画面ロックなどに使えます

## 使い方

1. [Releases](../../releases) から自分の PC に合った zip をダウンロードして展開します

   | PC | ファイル |
   |---|---|
   | Windows | `windows-amd64`（Snapdragon 搭載機は `windows-arm64`） |
   | Mac (M1 以降) | `darwin-arm64` |
   | Mac (Intel) | `darwin-amd64` |
   | Linux | `linux-amd64` / `linux-arm64` |

2. `palm-deck` を起動します
   - **Windows**: `palm-deck.exe` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら「詳細情報」→「実行」を選びます。ファイアウォールの確認が出たら「プライベート ネットワーク」を許可してください
   - **Mac**: ターミナルで `xattr -d com.apple.quarantine palm-deck` を実行してから `./palm-deck` を実行します（署名していないため、最初の1回だけ必要です）
   - **Linux**: `./palm-deck` を実行します。ufw を使っている場合は `sudo ufw allow 8765/tcp` も実行してください

3. PC のブラウザに QR コードのページが自動で開くので、PC と**同じ Wi-Fi** につないだスマホで読み取ります（ターミナルにも同じ QR コードが出ます。ページを閉じてしまったら http://localhost:8765/qr で開き直せます）

4. ブラウザのメニューから「ホーム画面に追加」すると、次からはアイコンをタップするだけで開けます

## ページ

最初から次のページが入っています。画面下のタブで切り替えます。

| ページ | できること |
|---|---|
| メイン | 曲の操作、音量、ブラウザ、画面ロック など |
| Zoom | 起動、マイク、ビデオ、画面共有、手を挙げる、退出 |
| OBS | 起動、配信・録画の開始/停止（中は赤く光って経過時間を表示）、シーン切り替え（今のシーン名を表示）、仮想カメラ |
| YouTube | 開く、再生/停止、10秒戻る/進む、前/次の動画、全画面、ミュート、字幕 |
| Spotify | 起動、再生/停止（再生中は表示が変わる）、前/次の曲、再生中の曲名、音量 |
| Discord | 起動、マイクミュート、スピーカーミュート |

アプリごとに準備が必要なものがあります（[アプリごとの準備](#アプリごとの準備)）。

## PC でボタンやページを編集する

PC のブラウザで **http://localhost:8765/edit** を開きます（起動時にターミナルにも表示されます。QR コードのページにもリンクがあります）。

- **ページ**: 左の「＋ ページを追加」で空のページを作れます。✎ で名前の変更、↑↓ で並べ替え、🗑 で削除（ボタンが入っているページは 2 回押すと削除）
- **ボタン**: 「＋ 空のボタン」か「用意されたボタンから追加」で追加し、押すと右で名前・アイコン・色・押したときの動作・状態の表示を設定できます
- **アイコン**: 絵文字のほか、画像も使えます。「画像を選ぶ」か、画像をアイコン欄にドラッグして入れます（PNG・JPEG・GIF・WebP・ICO・SVG、2MB まで）。「サイトのアイコンを取得」で、URL のサイトのアイコンを取ってくることもできます
  - 「画像をボタン全体に広げる」をオンにすると、画像がボタンいっぱいに表示され、名前は画像の上に重ねて出ます。写真や、文字まで描き込んだ画像に向いています（ボタンの形に合わせて画像の端が切れます）
- **大きさ**: ボタンごとに、横・縦に何マス使うかを選べます。よく押すボタンや、曲名など長い文字を出すボタンを大きくすると便利です
- 「実行」で、保存する前にそのボタンの動作を PC で実行して試せます
- ボタンはドラッグで並べ替えられ、左のページ名にドラッグするとそのページへ移動します
- 上の「OBS の接続」で OBS のパスワードを設定できます
- 「保存」（Ctrl+S）で `buttons.json` に書き込みます。スマホの画面は開き直すと反映されます

### アプリのロゴ

「アプリのロゴを取得」を押すと、Zoom・OBS・YouTube・Spotify・Discord の「〜を開く」ボタンに、それぞれの公式サイトのアイコンを入れます。

ロゴは各社の商標なので、配布している Palm Deck には入れていません。押したときに公式サイトから取ってきて、この PC の設定フォルダ（`icons/`）にだけ保存します。自分のボタンの見た目として使うためのものなので、取ってきた画像をほかで配ったりはしないでください。

### ほかのプログラムからボタンを押す

スクリプトなどから、ボタンの ID を指定して押せます（トークンは設定フォルダの `token` ファイルにあります）。

```
curl -X POST -H "X-Token: トークン" http://localhost:8765/api/run/ボタンのID
```

この画面ではコマンドも書けるので、この PC で `localhost` として開いたときだけ使えます（スマホやほかの PC からは開けません）。

## 表示するボタンを選ぶ

スマホの画面右上の ⚙️ を押すと設定画面が開きます。

- 上のページ名を押すと、そのページのボタンを編集できます
- ボタンをドラッグして、マス目の好きな位置に並べ替えられます
- 下の「非表示」の枠にドラッグしたボタンは画面に表示されなくなります（消えるわけではないので、上の枠に戻せばまた表示されます）
- ボタンをタップしても、表示と非表示を切り替えられます
- ボタンを上のページ名にドラッグすると、そのページへ移動します
- 列の数を 1〜6 で変えられます

「保存」を押すと PC の `buttons.json` に書き込まれるので、どのスマホから開いても同じ並びになります。

## ボタンを変える

上の編集画面のほか、`buttons.json` を直接書き換えても変えられます（スマホからは変えられません）。保存したら、スマホで画面を開き直すだけで反映されます。

| OS | 場所 |
|---|---|
| Windows | `%AppData%\palm-deck\buttons.json` |
| Mac | `~/Library/Application Support/palm-deck/buttons.json` |
| Linux | `~/.config/palm-deck/buttons.json` |

```json
{
  "columns": 3,
  "pages": ["メイン", "配信"],
  "buttons": [
    { "id": "play",  "label": "再生/停止", "icon": "⏯", "color": "#3b82f6", "action": "media.playpause" },
    { "id": "notes", "label": "メモ",      "icon": "📝", "color": "#8b5cf6", "cmd": "code ~/notes" },
    { "id": "rec",   "label": "録画",      "icon": "⏺", "page": "配信",
      "action": "obs.record.toggle", "status": "obs.recording", "onIcon": "🔴", "onColor": "#ef4444" },
    { "id": "zoom-mic", "label": "Zoom マイク", "icon": "🎙", "page": "配信", "keys": "alt+a" }
  ]
}
```

- `id` はボタンごとに別の名前にしてください
- `page` はボタンを置くページです（省略すると最初のページ）。`pages` はページの並び順です
- `image` は画像アイコン（設定フォルダの `icons/` の中のファイル名）、`"imageFill": true` はその画像をボタン全体に広げます
- `columns` は列の数、`"hidden": true` は画面に出さないボタンです（スマホの設定画面で変えたときも、これらが書き込まれます）

### 押したときの動作（どれか1つ）

- **`action`**: あらかじめ用意された操作
  - `media.playpause` / `media.next` / `media.prev`: 曲の再生・停止 / 次の曲 / 前の曲（今鳴っているプレイヤー）
  - `volume.up` / `volume.down` / `volume.mute`: 音量を上げる / 下げる / ミュート
  - `mic.mute`: マイクのミュート（Mac は入力音量を 0 にして戻します。Windows は未対応）
  - `screen.lock` / `screen.off`: 画面ロック / 画面オフ
  - `spotify.playpause` / `spotify.next` / `spotify.prev`: Spotify を名指しで操作します
  - `obs.stream.toggle` / `obs.record.toggle` / `obs.virtualcam.toggle`: OBS の配信 / 録画 / 仮想カメラの開始・停止
  - `obs.scene.next` / `obs.scene.prev`: OBS の次 / 前のシーンへ
  - `obs.scene:シーン名`: OBS のシーンを切り替えます
  - `obs.mute:音声ソース名`: OBS の音声ソース（例: `obs.mute:マイク/AUX`）のミュート
- **`keys`**: キーを押します（例: `ctrl+shift+m`、`alt+a`、`cmd+shift+a`、`k`、`f5`）
  - 修飾キーは `ctrl` / `shift` / `alt`（Mac の option）/ `cmd`（Mac の ⌘、Windows キー、Super キー）
  - `"focus": "YouTube"` を一緒に書くと、タイトルにその文字を含むウィンドウを前に出してからキーを押します（Mac はアプリ名を書きます。例: `"focus": "Discord"`）
- **`text`**: 文字を入力します（例: `"text": "テストを実行して"`）。Claude などへのよく使う指示や定型文に使います
  - `"enter": true` を一緒に書くと、入力したあと Enter を押します。`focus` も `keys` と同じように使えます
  - 日本語も入力できます。Mac はクリップボード経由で貼り付けるので、一瞬クリップボードが書き換わります（終わったら元に戻します）
  - Linux は X11 なら xdotool、Wayland なら wtype か ydotool が必要です。GNOME の Wayland では wtype が動かないため、ydotool で英数字と記号だけを入力します
- **`open`**: URL やファイル、フォルダを開きます（`~` はホームフォルダを表します）
- **`cmd`**: 好きなコマンドを実行します（Windows では cmd.exe、Mac と Linux では sh で実行されます）

### 状態の表示（どちらか1つ、省略可）

画面を開いている間、2秒ごとに状態を調べてボタンに表示します。

- **`status`**: あらかじめ用意された状態
  - `audio.muted` / `audio.volume`: スピーカーのミュート / 音量
  - `mic.muted`: マイクのミュート（Windows は未対応）
  - `spotify.playing` / `spotify.track`: Spotify が再生中か / 再生中の曲名
  - `obs.streaming` / `obs.recording` / `obs.virtualcam`: OBS が配信中 / 録画中 / 仮想カメラ使用中か（配信・録画中は経過時間も出ます）
  - `obs.scene`: 今のシーン名。`obs.scene:シーン名` と書くと、そのシーンのときに光ります
  - `obs.muted:音声ソース名`: OBS の音声ソースがミュート中か
- **`statusCmd`**: 状態を調べるコマンド。`on` / `off`（`true` / `false` なども可）を出力するとボタンが光る・消える、それ以外の文字を出力するとボタンに表示されます（例: `"statusCmd": "date +%H:%M"`）

状態が on のときは、ボタンが白い枠で光ります。`onIcon` / `onColor` を書くと、on のときのアイコンと色を変えられます。

設定画面で保存すると `buttons.json` は書き直されるため、自分で入れた改行や、上にない項目は消えます。

### 前のバージョンの buttons.json を使っている場合

`buttons.json` は最初の起動時にだけ作られます。新しい初期セット（Zoom・OBS などのページ）を使うには、今の `buttons.json` を別の名前に変えてから起動し直してください。新しい `buttons.json` が作られます。

## アプリごとの準備

- **Zoom**: Zoom の「設定 → キーボードショートカット」で、使うショートカット（ミュート Alt+A など）の「グローバルショートカットを有効にする」にチェックを入れてください。Zoom が後ろにあっても効くようになります
- **OBS**: OBS（28 以降）の「ツール → WebSocket サーバー設定」で「WebSocket サーバーを有効にする」にチェックを入れてください。「認証を有効にする」にしている場合は、表示されたパスワードを `buttons.json` に書きます

  ```json
  "obs": { "password": "表示されたパスワード" },
  ```

  OBS を起動していないときは、ボタンに「⚠ 未接続」と出ます
- **YouTube**: ブラウザの YouTube のウィンドウを前に出してから、YouTube のショートカット（k: 再生/停止 など）を押します。YouTube を開いているタブを表示しておいてください（Mac では前に出せないので、ブラウザを前に出しておいてください）
- **Spotify**: 準備は不要です。曲名の表示は Mac と Linux はそのまま、Windows は Spotify のウィンドウのタイトルから読み取ります
- **Discord**: Discord のウィンドウを前に出してから、Discord のショートカット（Ctrl+Shift+M: マイクミュート など）を押します

## 起動オプション

```
palm-deck -port 8765      # ポート番号を変える
palm-deck -dir ./mydeck   # 設定ファイルの置き場所を変える
palm-deck -no-browser     # 起動時にブラウザで QR コードを開かない
```

## 安全性

- スマホから実行できるのは `buttons.json` に書いたボタンだけです。任意のコマンドは送れません
- ボタンの中身を変えられる編集画面 (`/edit`) と QR コードのページ (`/qr`) は、この PC から `localhost` で開いたときだけ使えます
- QR コードに含まれるトークンがないと操作できません。トークンは設定フォルダの `token` ファイルに保存されています。漏れたかもしれないときは、このファイルを削除して再起動すると新しいトークンが作られます
- スマホと PC の間の通信は暗号化されていません（http）。自宅など、信頼できるネットワークで使ってください

## OS ごとの注意

- **Windows**: 画面上部に今の音量は表示されません（操作はできます）。マイクのミュート（`mic.mute` / `mic.muted`）は未対応です
- **Mac**: メディアキーと画面ロックを使うには、初回に「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でターミナルを許可する必要があります
- **Linux**: 音量は PipeWire (`wpctl`) か PulseAudio (`pactl`) で、メディア操作は MPRIS (`playerctl` があればそれを使います) で行います
- **Linux**: キー操作（`keys`）には `xdotool`（X11）か `ydotool`（Wayland）が必要です（`sudo apt install xdotool ydotool`）。Wayland では、ウィンドウを前に出す（`focus`）のは X11 で動いているアプリ（Zoom、Discord、OBS など）だけに効きます。`ydotool` は `ydotoold` を起動しておく必要があります
- **Mac**: キー操作（`keys`）を使うには、「システム設定 → プライバシーとセキュリティ → アクセシビリティ」でターミナルを許可する必要があります

## 開発

```
go run .          # 起動
go test ./...     # テスト（OBS は偽のサーバーを相手に確かめます）
./build.sh v1.0.0 # dist/ に全 OS 向けの zip を作る
```

`v1.0.0` のようなタグを push すると、GitHub Actions が全 OS 向けの zip を Releases に公開します。
